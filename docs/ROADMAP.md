## P2 · 功能增强

### 1. EPG 官方源适配器：卫视 / 地方台（已排期，等紧急修改后提醒）

**现状**

- CCTV 已接入 CNTV 非官方 JSON 接口（`api.cntv.cn/epg/epginfo`），作为增强源：
  18 个频道 / 787 条节目，与 XMLTV 合并时同起始时间优先。
- 卫视、地方台、港澳台仍完全依赖 XMLTV（fanmingming、epg.pw 等）。

**目标**

为高频频道增加「官方/半官方接口」适配器，例如：

| 频道 | 候选来源 |
| --- | --- |
| 湖南卫视 | 芒果 TV 节目单接口 |
| 浙江卫视 | 中国蓝 TV / 官网节目单 |
| 江苏卫视 | 荔枝网节目单 |
| 东方卫视 | 看看新闻 / 官网节目单 |
| 北京卫视 | 北京时间 / 官网节目单 |

**实现方式**

- 复用 `packages/core/src/epg/cctv.ts` 的模式：`parseXxxEpg()` 纯函数 + runner 抓取适配器
- 合并规则与 CCTV 一致：同一频道同起始时间，官方源覆盖 XMLTV；未来时段保留 XMLTV
- 每个适配器失败只记 warning，不影响主流程
- 优先做 3–5 个台，验证收益后再扩展

**风险**

- 各台接口不公开、可能加签/改版，维护成本高于 XMLTV
- 仅覆盖单台，无法替代 XMLTV 底座
- 注意各站使用条款，控制请求频率

**验收**

- `npm run epg` 日志里出现对应适配器的频道/节目数
- 生成 XML 中该频道节目数明显增加，且时间与官网一致
- 适配器异常时 EPG 仍能由 XMLTV 正常生成
