## EPG 别名与匹配（暂缓，空闲时做）

- **背景**：EPG 覆盖率约 53%，缺口主要是公共节目单没有的地方台，以及台名写法对不上导致的未映射。
- **现状做法**：在「EPG 覆盖与映射」工作台人工绑定台名 → 频道；单频道也可在频道详情里加别名。效率低。
- **候选方案**（可叠加）：
  1. 自动候选 + 一键确认（推荐，约半天）：为每个未映射台名生成 1–3 个候选频道，确认后写入别名，下次自动命中。
  2. 高置信度自动绑定（约 +半天）：候选唯一且分数高时自动绑，标记“自动”并支持撤销。
  3. 地方台别名种子字典（约一天）：从公开节目单导出「地区 + 台名」清单，批量导入。
- **注意**：节目单源本身没有的台，补别名也变不出节目；`x-` 幽灵线路（约 1.7 万条）不适用别名，需合并频道或清理。
- **幽灵线路处理（与别名任务一起做，暂缓）**：约 1.5 万条 `x-` 频道线路不在频道库，探测会被过滤、发布也不会输出；届时决定「合并到已有频道 / 自动建频道 / 从待测统计中排除」。用户 m17512 要求归到本任务一起解决。

## 概览页接口合并（提议，暂缓）

- **背景**：2026-11-12 反馈后台/前台打开慢。实测（本机到 Cloudflare 香港边缘）：TLS 约 0.6s、每次请求往返约 0.2s；`/api/version` 0.81s、`/api/public/overview` 1.0–1.3s、`/api/admin/stats` 1.7s、`/api/admin/tasks` 2.1s、`/api/admin/sources` 1.5–2.0s、`/api/admin/pool/lines?limit=20` 冷 12.5s / 热 1.6s；首轮曾出现 60–90 秒超时（疑似本地链路/边缘抖动）。
- **现状**：概览页并发 6 个接口——stats、usage、settings、storage/sizes、tasks，以及全局布局里的 version。
- **提议**：新增 `GET /api/admin/overview`，在 Worker 内并行读取 stats/usage/settings/storage/tasks 并原样打包；概览页只调这一个；旧接口全部保留。
- **约束**（2026-11-12 讨论确认）：
  - 版本号继续独立请求，不并入（全局布局都用）。
  - 每块独立容错：单块读取失败只返回该块的空值 + `error` 标记，前端照旧显示对应区域错误态。
  - 可选 10–15 秒短缓存，数据最多晚 15 秒。
- **其他未实施优化**（按收益/风险排序）：`/assets/*` 一年强缓存 + immutable（高收益、低风险）；stats/tasks 短缓存；tasks 只取最近 20 条运行、来源改计数；用量/容量按需加载。
- **状态**：用户决定先不改，仅记录。

## 抓源失败用国内代理兜底（方案 v1，暂缓）

- **背景**：Cloudflare Worker 与 GitHub Actions 都是机房出口，部分源站只允许国内住宅/特定运营商 IP（如只开给陕西电信的组播源）。现在国内代理只用于拉代理订阅和补测线路，不参与抓源。
- **现状**：抓源在 `packages/runner/src/pipeline/collect.ts` 的 `fetchPlaylist`（直连 → TLS 失败重试 → `fetch_mode=worker` 代拉）；runner 已有 `fetchViaProxy`（HTTP CONNECT / SOCKS5）、`probeProxy` 和加密的代理库。
- **v1 方案**：
  1. 设置里加开关「机房抓取失败时用国内代理重试」，默认关。
  2. 仅对可重试错误触发：403/401、连接被拒、超时、DNS 失败；404、证书错误、非播放列表不重试。
  3. 取第一个「启用、非需内核、测活可用」的代理，走 `fetchViaProxy`，超时 60 秒、并发 1，只试一次；失败保留原始错误。
  4. 单源「抓取方式」增加「自动（失败走代理）」与「仅代理」，优先级高于全局开关。
  5. Worker 代拉返回 403/502 时，runner 用源地址走代理再抓一次。
  6. 任务消息与运行记录写「代理重试成功 X / 失败 Y」，源卡片错误标注「直连失败，代理也失败」。
- **限制**：Worker 不能走代理（Cloudflare 不支持）；代理必须支持 CONNECT；带宽/流量归代理所有者；源站若只放行住宅 IP，代理也可能失败；24MB 大列表走代理会慢。
- **工作量**：约 0.5–1 天；不改表结构（复用 `fetch_mode` 加两个值 + 一个设置项），测试 3–5 例。
- **状态**：2026-11-12 用户决定记录，暂不排期。
